# AI Teaching: Using GPT-6 Astra for 3D Graphics, Game Development, and Vibe Coding

## Overview

This AI Teaching demonstrates how to leverage GPT-6 Astra (OpenAI's frontier model) for creating 3D graphics, developing multiplayer video games, building desktop applications, and controlling computers through AI agents. Riley Brown shares seven realizations from using GPT-6 Astra for a week, showing practical workflows with Codex (OpenAI's coding agent), Blender, and computer use capabilities.

## When to Follow These AI Teachings

- When you need to create 3D graphics and digital assets using AI
- When developing multiplayer video games with minimal coding
- When building desktop applications through vibe coding
- When you want AI to control your computer for automated workflows
- When you need AI to self-test and iterate on complex tasks
- When setting up 24/7 AI agent infrastructure on local hardware

## Steps

### Step 1: Use GPT-6 Astra with Blender for 3D Asset Creation

Pass detailed inputs like PDFs containing floor plans or reference images to Codex with GPT-6 Astra to generate accurate 3D models in Blender. GPT-6 Astra can create game-ready assets and photorealistic renders in approximately 20 minutes. Use this workflow for estates, buildings, vehicles, or any complex 3D structure by providing detailed reference materials.

### Step 2: Integrate 3D Assets into Multiplayer Video Games

Once GPT-6 Astra creates a 3D model in Blender, instruct it to add the asset directly into multiplayer video games like Call of Duty-style games. GPT-6 Astra can create new playable maps, add vehicles like helicopters, and help verify the map builds successfully in the game format. This workflow enables game content creation where the user can test integration by playing the game to verify functionality.

### Step 3: Create Desktop Applications Through Vibe Coding

Use GPT-6 Astra inside Codex to spawn desktop applications with zero coding knowledge. Describe the app functionality in natural language, specifying features like keyboard shortcuts, image search, background removal, and file management. GPT-6 Astra can build functional apps in 16 minutes, handling everything from UI design to local file system integration. Deploy the app as a keyboard shortcut that lives on your computer for immediate use.

### Step 4: Host Applications and Games on ChatGPT Sites

Create web-based applications and games using ChatGPT Sites, which provides built-in hosting, database storage, and authentication. Instruct GPT-6 Astra to build lead magnets, admin dashboards, and interactive experiences that can be shared via link. Set up team authentication and admin access controls through natural language prompts.

### Step 5: Enable Full Computer Control with Codex

Install Codex and enable the computer use skill to give GPT-6 Astra full control over your desktop. GPT-6 Astra can open applications like Blender, take screenshots, evaluate visual output, fill out forms, test websites, and perform any computer task autonomously. This capability is available when using Codex, which provides access to local tools, browser tabs, and signed-in applications.

### Step 6: Implement AI Self-Testing Loops

Configure GPT-6 Astra to autonomously iterate on tasks by implementing self-testing workflows. Instruct GPT-6 Astra to complete a task, evaluate its output through screenshots or testing, identify improvements needed, reprompt itself, and re-evaluate until the output matches the specified requirements. This works for Blender modeling, game development, and any complex multi-step task where GPT-6 Astra can verify its own work through observation or testing.

### Step 7: Set Up 24/7 AI Agent Infrastructure

Deploy Mac Mini or local Linux machines running Codex and other AI agents continuously for always-available AI assistance. Configure remote access from phones and laptops to control the Mac Mini from anywhere. Run multiple AI providers (OpenAI, Anthropic, Grok) simultaneously on the same machine. Keep all API keys, GitHub access, and signed-in applications available to GPT-6 Astra for productivity and quick context switching between tasks.

## Best Practices

- ✅ Provide detailed reference materials like PDFs, images, and floor plans for 3D asset creation
- ✅ Let the AI test its own work by taking screenshots and evaluating output; play games to verify functionality
- ✅ Use Codex instead of web-only interfaces to access local tools, browser tabs, and signed-in applications
- ✅ Deploy Mac Mini or local machines for 24/7 AI agent availability
- ✅ Specify exact end states so the AI can iterate until the output matches the requirements
- ❌ Don't rely solely on web-based AI interfaces that lack computer control
- ❌ Don't expect complete results on first attempt - leverage the AI's self-testing loop
- ❌ Don't forget to sign into all applications on the machine running Codex

## Security & Safety Notes

- AI agents with full computer control can delete files and modify system settings - verify actions before allowing destructive operations
- Admin dashboards and authentication should be configured carefully to prevent unauthorized access
- API keys stored on local machines running AI agents should be properly secured
- AI-generated code should be reviewed before deployment to production environments
- Computer use capabilities could be misused if the AI is given malicious prompts

## Common Pitfalls

- **Problem:** AI creates 3D models with incorrect textures or colors
  **Solution:** Let the AI self-test by taking screenshots and evaluating the output, then reprompting with specific corrections
- **Problem:** Desktop apps built by AI do not include all requested features
  **Solution:** Provide detailed feature specifications in the initial prompt and iterate through the self-testing loop
- **Problem:** Games created by AI don't build successfully
  **Solution:** Instruct the AI to test the build process, capture error screenshots, and fix issues automatically through iteration
- **Problem:** AI loses context or forgets project details during long sessions
  **Solution:** Keep all work on a single dedicated machine with persistent Codex sessions
- **Problem:** Remote access to AI agents is unreliable
  **Solution:** Use Mac Mini setups with remote desktop software and ensure the machine never sleeps
