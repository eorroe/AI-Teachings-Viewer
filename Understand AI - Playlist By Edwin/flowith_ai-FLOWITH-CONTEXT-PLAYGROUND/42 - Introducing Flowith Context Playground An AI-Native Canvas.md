# Introducing Flowith Context Playground: An AI-Native Canvas

## Overview

Flowith Context Playground is an AI-native canvas built around a node-based graph. The video describes it as a tool where "each node holds one discrete piece of context (a source document, a character profile, a scene description, or a prompt). You connect nodes together, route them into AI generation nodes for text, image, or video output, and refine individual nodes to control exactly what the AI receives." Each context element gets its own editable, traceable node, replacing unstructured copy-paste workflows.

## When to Follow These AI Teachings

- When you need to visually construct and organize AI context for projects that require interconnected context sources
- When working with AI-generated outputs (text, images, or video) that must be combined into a single coherent output
- When batch generating content across text, image, and video formats from a unified context
- When AI hallucinations (false or unsourced information generated by AI) in output need to be reduced through node-level context control

## Steps

### Step 1: Set Up Your Context Canvas

Open the Flowith Context Playground and begin with an empty canvas. This canvas serves as your workspace for building AI context through connected nodes.

### Step 2: Build Nodes by Duplicating and Dragging

Create context structures using the drag-and-drop interface in the right-hand node panel. Right-click a node and select "Duplicate" to clone it, then click and drag to reposition. Hold Shift and click to multi-select nodes, then drag the group to arrange them together. Build your context like modular building blocks: one node per source document, character, scene, or concept.

### Step 3: Generate Node Libraries with AI

Click the AI agent button in the toolbar and enter a prompt such as "Generate a library of 10 nodes for a sci-fi video script including: protagonist, antagonist, setting, inciting incident, rising action, climax, resolution, theme, visual tone, and dialogue style." The AI agent will generate a library of high-quality nodes so you do not build each node manually.

### Step 4: Mix, Match, and Batch Generate

Connect output nodes to a batch-generate node. Select source nodes and route them into a single text-generation, image-generation, or video-generation node. The playground produces outputs across text, image, and video formats.

### Step 5: Refine Node-Level Control

Click any individual node to open its content editor. Edit the text, prompt, or parameters directly in that node's panel. Changes to one node propagate to connected downstream nodes, so you can refine context elements in isolation before regenerating downstream outputs.

### Step 6: Consolidate Creative Fragments

Confirm all source nodes, intermediate outputs, and generated content remain visible on a single canvas. Use the canvas zoom and pan controls to review the full graph. A fully visible, connected graph preserves context coherence across generation cycles.

## Examples

### Example 1: Content Pipeline Construction

A creator producing a 5-minute YouTube video can: (1) duplicate a character node to create variants for the host and guest; (2) drag scene nodes for intro, main segment, and outro onto the canvas; (3) use the AI agent to generate supporting nodes for B-roll prompts, thumbnail copy, and description tags; (4) batch-generate script drafts, character reference images, and storyboard frames from the unified canvas in a single workflow.

### Example 2: Reducing AI Hallucinations

A researcher compiling a literature review can: (1) add one source node per academic paper with title, authors, year, and key findings; (2) multi-select all source nodes and connect them to a "synthesize" node; (3) refine each source node to ensure claims are verbatim or clearly attributed; (4) generate a summary output with fewer hallucinations because every claim traces back to an explicitly defined source node.

## Best Practices

- ✅ Right-click a node and select "Duplicate" to clone context rather than retyping it, which preserves exact wording and formatting across nodes
- ✅ Hold Shift, click each node, then drag to multi-select related nodes before applying batch edits or connecting them to a shared output node
- ✅ Use the AI agent (toolbar button) to generate a library of nodes at once rather than adding nodes one at a time manually
- ✅ Open each node's editor panel and refine its content before connecting it to a batch-generate or output node
- ✅ Keep all source nodes, intermediate outputs, and generated content on a single canvas rather than distributing them across separate documents or tabs
- ❌ Do not paste raw text into a node's editor without first creating a dedicated node for it, because unnodeified content cannot be routed or batch-processed
- ❌ Do not run batch generation before refining every source node; unrefined nodes propagate imprecise or hallucinated context into all downstream outputs
- ❌ Do not copy context out of the canvas into external files during active work, because fragments outside the canvas lose their connection to the node graph

## Keep In Mind

- Construct context using nodes rather than pasting large text blocks into a single node
- Every node's content flows into downstream outputs; a single under-defined node can cause all connected batch outputs to produce generic, off-target, or hallucinated content
- Batch generation supports text, image, and video output formats when the upstream context nodes are fully defined and connected
- Node edits propagate to downstream connected nodes, so earlier context nodes act as a persistent foundation for generation cycles

## Security & Safety Notes

- Open each AI-generated node and verify its content against the source material before connecting it to nodes used for downstream batch generation
- When batch-generating outputs from context nodes containing PII (Personally Identifiable Information), financial data, or regulated content, review outputs against their source nodes before sharing externally
- Treat every node-generated output as a draft requiring verification against its source nodes before sharing externally
- Export your canvas and store it in a version-controlled location if it contains proprietary business logic, source material, or client context

## Common Pitfalls

- **Problem:** A single under-defined node causes all batch outputs connected to it to produce generic, off-target, or hallucinated content. **Solution:** Open every node before batch generation and confirm it contains fully defined content with specific attributes (for example, a character node should include name, role, personality traits, backstory, and dialogue style).
- **Problem:** Copying context into external documents or tabs during active work breaks the node graph, causing downstream batch outputs to fall out of sync with the canvas. **Solution:** Keep all source material inside nodes on the canvas. If you need to reference external material, create a dedicated source node for it rather than storing it outside the canvas.
- **Problem:** Using copy-paste to insert raw text into a node's content area instead of creating a structured node. Pasted text cannot be routed, connected, or refined independently. **Solution:** Create a new node per source, concept, or entity (one node per character, scene, or document), then paste the content inside that node's editor rather than into a catch-all text node.

## Glossary

- **AI-native canvas**: A workspace built around a node-based graph where each node holds one discrete piece of context (a source document, character profile, scene description, or prompt), connected and routed into AI generation nodes for text, image, or video output.
- **Fully defined content**: Content within a node that includes specific attributes. For example, a fully defined character node includes name, role, personality traits, backstory, and dialogue style; a fully defined source node includes title, authors, year, and key findings.
- **Node**: An individual editable unit on the canvas that holds one discrete piece of context. Each node has its own content editor, and changes propagate to connected downstream nodes.
